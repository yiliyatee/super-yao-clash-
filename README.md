## 📱 导入方法

**Windows（Clash Verge Rev / mihomo-party）**
1. 打开客户端 → 「订阅 / Profiles」
2. 粘贴上面的订阅链接 → 「导入」
3. 选中该配置 → 开启系统代理即可

**Android（Clash Meta for Android）**
1. 配置 → 新建配置 → URL 方式
2. 粘贴订阅链接保存 → 启动

**iOS（Stash / Shadowrocket 等）**
1. 首页添加配置/订阅 → 粘贴链接 → 保存并启用

**更新建议**：把客户端「自动更新间隔」设为 **12~24 小时**，免费节点失效快，过期配置基本全挂。

## 🔗 国内直连不畅？加镜像前缀

`raw.githubusercontent.com` 在国内常被污染，连不上时在原链接前面拼一个镜像前缀即可：

```
https://ghproxy.net/https://raw.githubusercontent.com/xxx/xxx.yaml
https://gh-proxy.com/https://raw.githubusercontent.com/xxx/xxx.yaml
```

常用镜像站（换着用）：`ghproxy.net`、`gh-proxy.com`、`ghfile.geekertao.top`
