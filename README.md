## 📱 导入方法

**Android（Clash Meta for Android）**
1. 配置 → 右上角 ➕ → URL 方式
2. 粘贴上面的订阅链接 → 保存
3. 回主页选中该配置 → 点启动

**Windows（Clash Verge Rev / mihomo-party）**
1. 「订阅 / Profiles」页 → 粘贴链接 → 导入
2. 选中该配置 → 开启系统代理

**iOS（Stash / Shadowrocket 等）**
1. 首页添加配置/订阅 → 粘贴链接 → 保存并启用

**更新建议**：客户端「自动更新间隔」设为 **12~24 小时**，免费节点失效快，过期配置基本全挂。

**自检小技巧**：导入失败时，先用手机浏览器打开那条链接——能显示/下载一大堆文本就说明链接通，问题在客户端；打不开就换一条或换镜像前缀。

## 🔗 镜像前缀说明

`raw.githubusercontent.com` 在国内被 DNS 污染，直连基本不通。解决方式就是在原始链接前拼一个镜像前缀：

```
https://ghproxy.net/https://raw.githubusercontent.com/xxx/xxx.yaml
https://gh-proxy.com/https://raw.githubusercontent.com/xxx/xxx.yaml
```

常用镜像站（换着用）：`ghproxy.net`、`gh-proxy.com`
